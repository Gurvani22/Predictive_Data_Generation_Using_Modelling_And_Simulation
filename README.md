#  Data Generation using Modelling and Simulation

---

## 1️ Methodology

Generating random samples for simulation  
→ Applying machine learning models on the generated data  
→ Graphical display of data and evaluated parameters  

---

## 2️ Description

- **Simulator:** GEKKO  
- **Dataset:** Generated using simulation  
- **Number of Simulations:** 1000  

### Machine Learning Models Used:
- Linear Regression  
- Ridge Regression  
- Lasso Regression  
- Decision Tree  
- Random Forest  
- Support Vector Regressor (SVR)  
- K-Nearest Neighbors (KNN)  

- **Output:** Comparative performance table  

---

## 3️⃣ Objectives

- To generate a dataset using modelling and simulation.  
- To apply multiple machine learning models on simulated data.  
- To compare model performance using evaluation metrics.  
- To visualize the data and results graphically.
